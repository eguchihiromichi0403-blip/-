# 申告書PDF結合ツール

申告ソフトから書き出した書類ごとのPDFを、決まった順番で1つのPDFに結合するブラウザ用ツールです。

## 使い方

1. `index.html` をブラウザ（Chrome / Edge）で開く
2. PDFをまとめてドラッグ＆ドロップ（クリックして選択も可）
3. 判別結果を確認し、違っていればプルダウンで直す
4. ファイル名を確認して「結合してダウンロード」

## 結合する順番

1. 法人税受信通知
2. 税務代理権限証書
3. 消費税申告書
4. 法人税申告書
5. 地方税申告書
6. 法人事業概況書
7. 勘定科目内訳書
8. 決算報告書
9. 減価償却計算書

追加されていない書類は飛ばします。同じ種類のファイルが複数あるときは ↑↓ で順番を変えられます。

## 判別のしかた

- 1ページ目の文字（様式名など）で判別し、読み取れないときはファイル名で判別します
- 書類の中に他の書類名が出てくるため（例: 別表一の添付書類欄に「事業概況」「勘定科目内訳明細書」）、
  他の書類に出てこない表題から順に判定しています。ルールは `index.html` の `RULES` にあります
- 判別できなかったファイルは「判別できなかったファイル」欄に表示され、種類を選ぶまで結合しません

## 注意

- PDFはブラウザの中だけで処理され、外部には送信されません
- 処理用のライブラリ（pdf.js / pdf-lib）を cdnjs から読み込むため、開くときはインターネット接続が必要です
