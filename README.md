# 工事台帳インポートCSV（令和8年6月期→当期）

`templates/project_import_template.csv`（受領したひな型）の列構成に、
`work/source.xlsx`（工事一覧）を当てはめたものです。

## 生成物

`koji_daicho_2026.csv` — **44件** / UTF-8（BOM付き）/ CRLF / ひな型と同じ13列。

内訳: 進行中 20件・完成 16件・見積 8件、請負金額合計 93,720,858円（金額未入力 17件）。

## 抽出条件

6月決算のため、**工期終了が 2026/07/01 以降**の工事のみを対象にしています。

- 令和08年シート 94件 → 44件（前期以前に完成した50件を除外）
- 令和07年シート 86件 → 0件（すべて 2026/06/30 以前に完成）
- 完了日が未定の工事（進行中・見積 28件）は、当期以降に完成するものとして取り込み

## 列の対応

| CSV列 | Excel列 | 変換ルール |
|---|---|---|
| 工事番号 | （なし） | `2026-001` から工期開始順に連番を自動採番（未定は末尾） |
| 現場名 | 現場名 | 原文どおり（前後・連続空白のみ整理） |
| 得意先名 | 元請け名称 | `k2` `ｋ２` → `K2` のみ表記統一 |
| 得意先コード | （なし） | 空欄 |
| 工期開始 | 着工日 | `YYYY/MM` に変換 |
| 工期終了 | 完了日 | `YYYY/MM` に変換。欠落時は 着工日＋工事期間 で補完 |
| 請負金額 | 請負金額 | 整数。数値でないものは空欄 |
| 前期末未成工事支出金（4列） | — | **全件空欄**（下記「未反映のデータ」参照） |
| 状態 | 着工日・完了日から判定 | 着工日なし=見積 / 着工日が未来=受注 / 完了日が過去=完成 / それ以外=進行中 |
| 既定の原価区分 | 材料金額・外注費の大小 | 金額の大きい方。どちらも0なら空欄 |

状態の判定基準日は 2026-09-02。

## 元データの補正・注意点

補正の全件は `work/conversion_notes.txt` に記録。台帳に採用した工事のうち:

- **完了日の年ずれ**: 「加島1丁目有料老人ホーム新築工事」の完了日 `2月30日` は実在しない日付のため
  着工日＋工事期間で補完。「林様邸防水工事」は完了日が着工日より前だったため同様に補正
- **請負金額が数値でない**: 「メゾンベール六甲山手」は `清算工事` のため空欄
- **重複**: 「レオパレス千鳥橋」（得意先 K2）が2件登録されている（`2026-019` / `2026-023`）
- **金額未入力**: 17件は Excel 側に請負金額が無いため空欄

## 未反映のデータ

- Excel の `材料金額` `外注費`（実績原価）はひな型に対応列がないため取り込んでいません。
  期首 2026/06/30 をまたぐ工事は18件あり、原価は 材料費 3,858,584円 / 外注費 19,160,155円 です。
  これを「前期末未成工事支出金」に入れる場合はご連絡ください（スクリプトで切り替え可能です）。
- `粗利益率` `粗利益` `工事期間` `協力業者名` も対応列がないため未取り込みです。
- `得意先コード` は Excel に無いため全件空欄です。
