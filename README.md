# 工事台帳インポートCSV

`templates/project_import_template.csv`（受領したひな型）の列構成に、
`work/source.xlsx`（令和08年 工事一覧）を当てはめたものです。

## 生成物

| ファイル | 内容 |
|---|---|
| `koji_daicho_2026.csv` | 前期末未成工事支出金をすべて空欄にした版 |
| `koji_daicho_2026_原価区分期首残高あり.csv` | 未完成工事（進行中・受注）に既発生原価を期首残高として設定した版 |

いずれも 94件 / UTF-8（BOM付き）/ CRLF / ひな型と同じ13列。

## 列の対応

| CSV列 | Excel列 | 変換ルール |
|---|---|---|
| 工事番号 | （なし） | `2026-001` から着工日順に連番を自動採番 |
| 現場名 | 現場名 | 原文どおり（前後・連続空白のみ整理） |
| 得意先名 | 元請け名称 | `k2` `ｋ２` → `K2` のみ表記統一 |
| 得意先コード | （なし） | 空欄 |
| 工期開始 | 着工日 | `YYYY/MM` に変換 |
| 工期終了 | 完了日 | `YYYY/MM` に変換。欠落時は 着工日＋工事期間 で補完 |
| 請負金額 | 請負金額 | 整数。数値でないものは空欄 |
| 前期末未成工事支出金（材料費） | 材料金額 | 版により空欄／未完成工事のみ設定 |
| 前期末未成工事支出金（労務費） | （なし） | 空欄 |
| 前期末未成工事支出金（外注費） | 外注費（最大6社の合計） | 版により空欄／未完成工事のみ設定 |
| 前期末未成工事支出金（経費） | （なし） | 空欄 |
| 状態 | 着工日・完了日から判定 | 着工日なし=見積 / 着工日が未来=受注 / 完了日が過去=完成 / それ以外=進行中 |
| 既定の原価区分 | 材料金額・外注費の大小 | 金額の大きい方。どちらも0なら空欄 |

判定基準日は 2026-09-02。内訳は 完成66件・進行中20件・見積8件。

## 元データの補正・注意点

`work/conversion_notes.txt` に全件記録。主なもの:

- 完了日の年が1年前になっている7件（南扇町ビル、セラヴィー119、京都きもの、上六新興産ビル、
  HOT様大規模修繕、田中ハイツ、メイゾン高槻）を着工年に合わせて補正
- 「加島1丁目有料老人ホーム新築工事」の完了日 `2月30日` は実在しない日付のため、
  着工日＋工事期間で補完
- 「メゾンベール六甲山手」の請負金額は `清算工事` のため空欄
- 「レオパレス千鳥橋」（得意先 K2）が2件重複
- Excelの `粗利益率` `粗利益` `工事期間` `協力業者名` はひな型に対応列がないため取り込んでいない
